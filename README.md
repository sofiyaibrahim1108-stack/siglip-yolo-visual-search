#  SigLIP + YOLO Visual Search Project

An AI-powered visual search system that combines SigLIP embeddings and YOLO object detection to perform image retrieval, text-based search, and object-level analysis.

---

##  Project Overview

This project integrates SigLIP and YOLO to build an intelligent visual search engine capable of:

- 🔍 Text-to-Image Search
- 🖼️ Image-to-Image Search
- 🎯 Object Detection using YOLO
- 🧠 Semantic Similarity Search using SigLIP
- ⚡ Real-Time Processing
- ☁️ MongoDB Storage
